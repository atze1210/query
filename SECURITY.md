# Security Policy

## Supported Versions

Security updates are provided for the latest `5.x` release line.

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting flow:
https://github.com/TanStack/query/security/advisories/new

After a report is submitted, maintainers will triage it and follow up through
the advisory thread with status updates, remediation details, and disclosure
timelines.
